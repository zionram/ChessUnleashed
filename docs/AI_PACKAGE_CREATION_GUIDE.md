# AI Package Creation Guide

This guide explains how to ask an external AI assistant (ChatGPT, Claude, Gemini, etc.) to generate a package JSON file that can be loaded into the **AI Package Builder** tool in Chess Unleashed.

---

## What Is a Package?

A Chess Unleashed package is a JSON file that bundles together reusable configuration — themes, sounds, animations, bot settings, rules, and more. Packages can be created by hand, generated by an AI assistant, or built through the in-app editors and exported.

The AI Package Builder (found at **Advanced › Gaming › AI Package Builder**) accepts raw JSON, validates it against the package format, and lets you apply or save it as a draft.

---

## How to Use an AI Tool to Generate a Package

**For most users:** use the **Universal Package Prompt** — it covers all supported categories and works with any description.

1. Open **AI Package Builder** in Chess Unleashed (**Advanced › Gaming › AI Package Builder**)
2. Click **Copy Universal Package Prompt**
3. Paste the prompt into your preferred AI assistant (Claude, ChatGPT, Gemini, etc.)
4. Replace the last line ("My description: [...]") with what you actually want — e.g. "bounce animations on captures, easy bot difficulty, training wheels on"
5. Copy the JSON the AI produces
6. Paste it into the **Package JSON** textarea in Chess Unleashed
7. Click **Validate**
8. Review any warnings, and toggle categories on or off as needed
9. Click **Apply Package** to use it immediately, or **Save as Draft** to store it for later

**Specialized prompts** (Theme, Sound/Events, Animation, Full Experience) are available under "Optional: Specialized Prompts" in the tool. Use them when you want tighter control over a single category and don't need a combined package.

**Tips:**
- If the AI produces unknown field names, click **Normalize** to strip them automatically
- Sound rules that reference a sound ID not in `soundLibrary` will show a warning but will still be saved — you can add the actual audio file later via the Sound Editor
- For visual themes that need custom images, list the required images as a note outside the JSON and add them later via Layers or Piece Sets

## Chess Unleashed Package Format

### Top-Level Structure

Every valid package must follow this shape:

```json
{
  "format": "chess-unleashed-experience",
  "metadata": {
    "name": "Package Name",
    "version": "1.0.0",
    "description": "Optional description",
    "author": "Optional author"
  },
  "contents": { ... }
}
```

Only these top-level keys are valid:

| Key | Required | Notes |
|---|---|---|
| `format` | Yes | Must be exactly `"chess-unleashed-experience"` |
| `metadata` | Yes | Name and version are recommended |
| `contents` | Yes | One or more content categories (see below) |
| `assetManifest` | No | Only needed for zip-packed binary assets — AI-generated packages should omit this |

---

### Content Categories

The `contents` object may contain any combination of the following 20 categories. Include only the ones your package needs.

| Category Key | What It Contains |
|---|---|
| `template` | Board visuals, piece themes, background, frame layer, board overlay, audio controller appearance |
| `uiAppearance` | Platform colors, board size, density, tips board preferences |
| `timeControl` | Timer setup (not the live countdown — just the configuration) |
| `chatSettings` | Chat display preferences |
| `rules` | `gameMode` ("standard" or "custom"), `trainingWheels` (true/false) |
| `audio` | Legacy full audio profile (older format) |
| `audioSettings` | `masterVolume`, `musicVolume`, `sfxVolume` (each 0–1), `playbackMode` |
| `soundLibrary` | Array of `{ id, name, url }` sound asset definitions |
| `soundRules` | Array of AudioRule objects mapping game events to sounds |
| `audioPlaylists` | `bgMusic`, `bgMusicName`, `playlistName`, `playlist`, `currentTrackIndex`, `playbackMode` |
| `botSettings` | `difficulty` (1–10), `enablePersonality` (true/false), and other bot behavior preferences |
| `registeredBots` | Array of bot registrations (`{ id, name, type, path }`) |
| `personalityProfiles` | Map of bot personality configurations |
| `localProfile` | `displayName`, `profileImage`, `guestId`, `profileType` |
| `multiplayerServer` | `mode` ("official", "home", or "custom"), `homeUrl`, `customUrl` |
| `compliancePolicy` | Host-enforced room policy (runtime-only — normally not included in packages) |
| `customEvents` | Array of CustomEventDefinition objects |
| `animationDefinitions` | Array of AnimationDefinition objects |
| `animationRules` | Array of AnimationRule objects |
| `customRulesets` | Array of approved custom game ruleset definitions |

## Schema Reference

### AudioRule

Audio rules wire game events to sounds from your `soundLibrary`.

```json
{
  "id": "rule-unique-id",
  "name": "Optional rule name",
  "event": "pieceMoved",
  "piece": "any",
  "side": "any",
  "mode": "any",
  "soundId": "sound-id-from-library"
}
```

**Valid values:**

| Field | Valid Options |
|---|---|
| `event` | `afterMove`, `pieceMoved`, `pieceCaptured`, `check`, `checkmate`, `promotion`, `gameStart`, `gameEnd`, `panelOpened` |
| `piece` | `any`, `p` (pawn), `n` (knight), `b` (bishop), `r` (rook), `q` (queen), `k` (king) |
| `side` | `any`, `w` (white), `b` (black) |
| `mode` | `any`, `local`, `vsComputer`, `multiplayer` |

---

### CustomEventDefinition

Custom events let you define named triggers that animation rules and sound rules can target.

```json
{
  "id": "event-unique-id",
  "name": "My Event",
  "eventId": "my-event-id",
  "category": "custom",
  "baseTrigger": "pieceMoved",
  "conditions": {},
  "conditionMode": "all"
}
```

**Valid `baseTrigger` values:** `afterMove`, `pieceMoved`, `pieceCaptured`, `check`, `checkmate`, `promotion`, `gameStart`, `gameEnd`, `panelOpened`

---

### AnimationDefinition

Animation definitions describe how an animation looks and behaves.

```json
{
  "id": "anim-unique-id",
  "name": "My Animation",
  "description": "Description",
  "category": "Custom",
  "preset": "bounce",
  "targetType": "piece",
  "durationMs": 400,
  "delayMs": 0,
  "easing": "ease-in-out",
  "intensity": 0.7,
  "repeatCount": 1,
  "enabled": true,
  "status": "active"
}
```

**Valid values:**

| Field | Valid Options |
|---|---|
| `preset` | `snap`, `slide`, `fast-slide`, `bounce`, `hop`, `shake`, `pulse`, `capture-pop`, `promotion-glow`, `board-flash` |
| `targetType` | `piece`, `captured-piece`, `promoted-piece`, `board`, `ui` |

---

### AnimationRule

Animation rules connect a custom event to an animation definition.

```json
{
  "id": "animrule-unique-id",
  "eventId": "event-id-from-custom-events",
  "animationId": "anim-id-from-definitions",
  "target": "moved-piece",
  "scope": "any-piece",
  "enabled": true
}
```

**Valid values:**

| Field | Valid Options |
|---|---|
| `target` | `moved-piece`, `captured-piece`, `target-square`, `source-square`, `board`, `current-player-panel`, `fallback-preview` |
| `scope` | `any-piece`, `my-pieces`, `opponent-pieces`, `white-pieces`, `black-pieces` |

## Asset References

### What `package://` URLs Mean

When binary assets (images, audio files) are packed into a `.zip` package, their URLs are stored using the `package://` scheme, for example:

```
package://assets/audio/move-sound.mp3
package://assets/images/background.png
```

These references only resolve when the full `.zip` is loaded through **Package Manager › Load Package**. A plain JSON file with `package://` URLs will import without errors, but the assets will not appear until the zip is also loaded.

### AI-Generated Packages and Assets

AI tools cannot generate real image or audio files. When asking an AI to build a package that includes visual or audio assets, follow these rules:

- **Leave image fields as an empty string `""`** — the app will fall back to defaults
- **Leave sound URL fields as an empty string `""`** — sounds will be silent until you add the files manually
- **List required assets as a note outside the JSON**, for example:
  ```
  Required Assets:
  - background.png (1920×1080, board background)
  - move-sound.mp3 (short click sound for piece moves)
  ```
- **Never use local file paths** like `C:\Users\...` or `/home/user/...` — they will not resolve on any machine other than yours
- **Never use base64-encoded data** — it makes packages extremely large and breaks the format

---

## What NOT to Include

The following fields must **never** appear inside `contents`. They represent live game state and belong to Game Snapshots, not reusable packages:

- `fen`
- `moveHistory`
- `historyFens`
- `currentTurn`
- `timerState`
- `result`
- `gameState`
- `boardState`
- `selectedCustomRulesetId`
- `currentTurnIndex`

If an AI assistant includes any of these, remove them before importing — or click **Normalize** to strip unrecognized fields automatically.

## Example Packages

### Example 1: Minimal Rules and Bot Settings

A simple package that turns on training wheels and sets a beginner-level bot.

```json
{
  "format": "chess-unleashed-experience",
  "metadata": {
    "name": "Beginner Friendly Setup",
    "version": "1.0.0",
    "description": "Easy mode with bot hints"
  },
  "contents": {
    "rules": {
      "gameMode": "standard",
      "trainingWheels": true
    },
    "botSettings": {
      "difficulty": 3,
      "enablePersonality": true
    }
  }
}
```

---

### Example 2: Sound Rules Wired to Custom Events

A package that defines a sound library entry and triggers it on piece captures.

```json
{
  "format": "chess-unleashed-experience",
  "metadata": {
    "name": "Sound Events Package",
    "version": "1.0.0"
  },
  "contents": {
    "customEvents": [
      {
        "id": "evt-capture-001",
        "name": "Capture Event",
        "eventId": "capture-001",
        "category": "capture",
        "baseTrigger": "pieceCaptured",
        "conditions": {},
        "conditionMode": "all"
      }
    ],
    "soundRules": [
      {
        "id": "srule-001",
        "name": "Capture Sound",
        "event": "pieceCaptured",
        "piece": "any",
        "side": "any",
        "mode": "any",
        "soundId": "my-capture-sound"
      }
    ],
    "soundLibrary": [
      {
        "id": "my-capture-sound",
        "name": "Capture Hit",
        "url": ""
      }
    ]
  }
}
```

> **Note:** The `soundLibrary` entry has an empty `url`. The rule will be saved and active, but no audio will play until you add the actual audio file via the Sound Editor.

### Example 3: Animation Definitions and Rules

A package that plays a bounce animation on the captured piece whenever a capture occurs.

```json
{
  "format": "chess-unleashed-experience",
  "metadata": {
    "name": "Bounce Captures",
    "version": "1.0.0"
  },
  "contents": {
    "animationDefinitions": [
      {
        "id": "anim-bounce-cap",
        "name": "Capture Bounce",
        "description": "Bounce on capture",
        "category": "Capture",
        "preset": "bounce",
        "targetType": "piece",
        "durationMs": 400,
        "delayMs": 0,
        "easing": "ease-in-out",
        "intensity": 0.8,
        "repeatCount": 1,
        "enabled": true,
        "status": "active"
      }
    ],
    "customEvents": [
      {
        "id": "evt-cap",
        "name": "On Capture",
        "eventId": "on-capture",
        "category": "capture",
        "baseTrigger": "pieceCaptured",
        "conditions": {},
        "conditionMode": "all"
      }
    ],
    "animationRules": [
      {
        "id": "ar-001",
        "eventId": "on-capture",
        "animationId": "anim-bounce-cap",
        "target": "captured-piece",
        "scope": "any-piece",
        "enabled": true
      }
    ]
  }
}
```

## Prompting Tips for Better AI Output

When asking an AI to generate a package, being specific leads to better results. Here are some example prompts to get you started:

**For animations:**
> "Generate a Chess Unleashed package JSON that plays a 'shake' animation on the king piece whenever a check event occurs. Use the customEvents, animationDefinitions, and animationRules categories. Follow the Chess Unleashed package format exactly."

**For sounds:**
> "Create a Chess Unleashed experience package that defines a sound library with placeholder URLs, and adds sound rules that trigger different sounds for pawn moves versus queen moves. Use the soundLibrary and soundRules categories."

**For bot and rules:**
> "Write a Chess Unleashed package JSON with rules set to standard mode and trainingWheels enabled, and botSettings at difficulty 5 with personality enabled."

**For combined packages:**
> "Build a Chess Unleashed package that includes beginner rules (trainingWheels on, standard mode), a low difficulty bot (level 2), and a bounce animation triggered on checkmate. Output only the JSON."

Always end your prompt with: **"Output only valid JSON matching the Chess Unleashed package format."** This discourages the AI from wrapping the output in extra explanation that you'd have to strip out before pasting.

## Troubleshooting

| Problem | Solution |
|---|---|
| Validation shows "unknown field" warnings | Click **Normalize** to strip unrecognized fields |
| Sound rule warning: sound ID not found in library | Add a matching entry to `soundLibrary`, or add the sound via Sound Editor later |
| Package applies but images are missing | Image fields are empty strings — add your image files via Layers or Piece Sets |
| Animation plays but looks wrong | Adjust `intensity`, `durationMs`, or `preset` in `animationDefinitions` |
| AI included game state fields like `fen` | Remove those fields or click **Normalize** before applying |
| Package file is very large | The AI likely included base64 image data — remove it and use empty strings for asset URLs instead |
