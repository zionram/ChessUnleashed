# Known Limitations And Roadmap

Status: Current planning notes

## Known Limitations

- Custom Game animation support may be limited.
- Deeper tactical events such as pin, trapped piece, and no-safe-move are Planned/Future.
- Official server accounts, official profiles, usernames, rankings, and cloud identity are Planned.
- Custom multiplayer games are Experimental/Planned.
- Settings Builder and Validation areas may need clarification if unfinished.
- Full package QA still needs manual verification with large GIF/MP3/background packages.
- Browser/dev mode durable asset persistence may be session-only when Electron IPC storage is unavailable.
- MIDI playback/waveform support may be limited by browser capabilities.
- Custom Game bots are not current.
- Custom Game multiplayer is not current.
- Full keyframe/timeline animation scripting is Planned.
- Full tactical chess analysis is not current.

## Roadmap Candidates

- Manual package QA with large media.
- Durable asset cleanup/repair UI.
- Custom Game multiplayer planning.
- Custom Game bot integration planning.
- Expanded tactical event detection.
- Better manual save slots for Game Snapshots.
- Official server/profile/account architecture.
- Additional package validator diagnostics.

## Documentation Rule

When a system is unclear, mark it Needs verification instead of claiming it is finished.
